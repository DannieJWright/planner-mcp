# Implement Plan

Implement the Markdown plan file provided by the user. The plan file path or contents are provided below:

$ARGUMENTS

A plan file describes the intended work and its complete planning context, including requirements, constraints, decisions, knowledge gaps and findings, notes, open questions, and action items. Read and retain that full context while implementing the plan.

Implement **all requirements** in the plan file. Keep every constraint, note, knowledge-gap finding, decision, open question, and other relevant planning context in mind while choosing and carrying out the implementation. Do not silently omit or weaken a requirement because it is inconvenient or because the plan contains unresolved context; surface blockers when necessary and continue until all implementable requirements are addressed.
